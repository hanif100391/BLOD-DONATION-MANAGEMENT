#  **  BLOOD DONATION MANAGEMENT  **

Project Description: Blood Donation Management System

This project is a web-based Blood Donation Management System developed using HTML, CSS, and JavaScript. The system allows users to register as blood donors and request blood when needed. The main purpose of the system is to make it easier for patients to find compatible donors within their location.

Key Features:

Donor Registration

Users can register as blood donors by providing their name, blood group, division (location), and contact number.

Each donor’s registration time and details are stored in the system.

Blood Request

Users can submit a blood request by specifying their required blood group and location.

The system will automatically search for matching donors from the registered list.

Matching Donors

The system matches donors based on blood group and location.

If a match is found, the details (name, blood group, location, contact number, and registration date) are displayed for immediate contact.

Donor List Display

All registered donors are displayed in a public table.

Information includes name, blood group, division, contact number, and registration date.

Local Storage

Donor data is stored in the browser’s localStorage, ensuring that data is not lost after refreshing the page.
Technologies Used:

HTML5 – For structure of the web pages.

CSS3 – For styling and user-friendly design.

JavaScript – For form handling, data storage, donor matching, and dynamic display
